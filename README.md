

## Purpose of the prompt

I am repsonsible to broadcast alive the services of my church. I normally get the sermon text on Saturday and I need to extract the scriptures from it, and feed them in a software to display them along with the preacher during the service.  I used to do that manually, until I created a prompt to be executed in Office Copilot that does the work for me. The prompt in this excersise is an adaptation of that original prompt.


# How it works

The evluations executes the prompt passing a parameter with the sermon text, which are stored in the folder `Sermons`.
